## 踩过的坑（勿重犯）
- SearchReplace `replace_all` 每文件只替 1 处，多处需带唯一上下文逐条补。
- 中文系统 `rpm -q` 输出"未安装"导致依赖检查漏报，改用 `ls /usr/include/*.h` 判头文件。
- `uv export` 会写 `-e .` 行，致 `pip download` 报 "Directory '.' is not installable" 整批崩，须 sed 剔除。
- `source.tar.gz` 曾泄漏 Windows 侧 `.env`（含真实密钥），打包必须 `--exclude='.env'`。
- MySQL 旧版本号（8.0.40/8.0.42）无 minimal 构建会 404；当前 GA 是 8.0.46。
- `dl.min.io` 国际站已 410 下架，用 `dl.minio.org.cn`。
- 离线制品包可靠性取决于"源工程一致性"：Windows 改的脚本必须先同步到 VM 再打包，否则 bundle 带旧默认值装错目录。
