### 2.2 RAGFlow 全套（server + task executor + MySQL + Redis + ES + MinIO，第三方组件）

| 填写项 | 填写值 |
|--------|--------|
| CPU 架构 | x86_64（官方维护镜像） |
| 推荐物理核心数 | 8（解析 + 检索并发工况） |
| CPU 指令集依赖 | 无特殊要求；ES 与文档解析受益于主流服务器指令集 |
| 推荐内存 | 32 GB（生产口径） |
| 常驻内存 | 实测 7.4 GB（主容器 4.68 GB + ES 2.43 GB + MySQL/MinIO/Redis 0.29 GB，知识库近空） |

| 磁盘空间 | 镜像约 14.6 GB（ragflow 11.8 GB + ES 1.3 GB + MySQL 1.3 GB + MinIO 227 MB）；含索引与文档存储建议 ≥100 GB |
| 线程数是否可配置 | 是，task executor worker 数在 service_conf.yaml |
| NUMA/绑核要求 | 不适用 |
| OS | **Ubuntu 22.04** |
| 运行时 | 预装 **Docker**（Engine + Compose v2） |
| 带宽 | **3 Mbps** |
