## 2. 接口事实（本轮边界的地基）

写接口全集只有 16 个。对本轮关键的是：

- `POST /tasks` 接受 `parameters`（JSON 串）并**真实透传到工具**：`app/agents/nodes/invoke_capability.py:50` → `app/agents/tools/infer_tool.py:93`。工作台的参数录入因此无需新接口。
- `GET /capabilities` 返回 `CapabilitySummary`：`capability_id / tool_name / tool_version / model_version / display_name / scene / capability_type / adapter_type / status / note`。**含 `display_name`**（中文标题有真实来源）；**不含** `input_schema / default_params / max_images`，故参数契约前端自带。
- `GET /tasks` 仅 `scene / status / limit≤100`，无时间、无创建人、无 offset；`meta.total` 即本页条数。`TaskStats` 无分场景细分。
- **无取消接口**；`POST /tasks/{id}/retry` 是原地重置，不产生 `retry_of` 关联任务。
- **原始工具响应不可得**：`raw_result` 只存在于 LangGraph 运行期内存，落库列 `raw_results_json` 恒写 NULL（`app/repositories/task_repo.py:63,205`）且全仓库无读取处。
- **`business_ref` 在整个后端不存在**，方案 §10.2 的跨任务聚合无数据源；唯一真实聚合是 `mode=joint` 的 parent/`children`。
- `/auth/me` 只返回 `{logged_in, username}`，**无 role / 无权限 / 无数据范围**。
- 知识库可读者：`GET /ragflow/status`（doc_count、最近入库）、`GET /ragflow/chat/datasets`、`POST /ragflow/search`、`GET /ragflow/datasets/{ds}/documents/{doc}/chunks`、文档 file/预览。**没有**文档清单与解析/索引状态端点。
- **分页相关接口的真实能力**（批次 1 评审时逐个核对）：`GET /tasks` 只有 `limit≤100`，**无 offset/page**（`app/api/v1/task.py:327-332`），响应虽包 `PageResult{items, meta{total,page,page_size}}`（`app/core/response.py:85-94`），但 `meta.total` 就是本页条数、`page` 恒为 1；`POST /ragflow/search` 只有 `top_k`（`ge=1, le=20`，`app/api/v1/ragflow.py:77-80`），无翻页参数；`GET /tasks/review-matrix` 的 `limit` 可到 **5000**（默认 500，`app/api/v1/task.py:151-153`），但返回的是聚合矩阵（`sample_count/total/by_scene/low_confidence_band`），**不含逐样本行**，故争议样本列表仍只能来自 `/tasks` 的 100 条窗口。
- 无人消费但可用的既有接口：`GET /reports/{task_id}`、`GET /tasks/review-matrix`、`POST /capabilities/reload`。
- **任务不是"调工具→出报告"两步**（`app/agents/graph.py:111-168`）：能力选择 →（多候选歧义时 `scene_confirm` HITL）→ 能力解析 → 输入校验 → 调用工具 → 结果归一 → 依据检索 → 判级 → 路由：`grade.level ∈ {review, fail}` 进 `human_review`（LangGraph `interrupt`，任务停在"待复核"直到复核提交），`pass/defect` 走 `explain_metrics` → 两者最终 `generate_report`。前端因此必须把"待复核"呈现为**在等人**而非卡住，复核动作走 `POST /tasks/{id}/review`（`Command(resume=...)` 恢复）。
